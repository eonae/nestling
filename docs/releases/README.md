# Релизы

Заметка о выпуске описывает одну версию для того, кто обновляет
приложение с предыдущей. Она называет, что изменилось, показывает код
до и после и ведёт к главе гайда или рецепту, где новое описано
целиком. Все пакеты `@nestlingjs/*` выходят одной версией, поэтому
заметка одна на выпуск.

| Версия | Главное |
|---|---|
| [0.4.0](./v0.4.0.md) | Источник конфигурации за координатами другого источника — поле `needs`, пакет `@nestlingjs/config.vault`, недостижимая операция отказом фазы BUILD, природа шины полем `remote` объявления, отказ под `argv()` сообщением и кодом выхода `1`, `nats` в peer-зависимостях, правила линтера `conditional-spread` и `no-process-globals` |
| [0.3.0](./v0.3.0.md) | `build(argv(process.argv))`, привязки конфигурации на `run()`, `server()`, статус и развилка исходов в декларации, отказ по HTTP документом RFC 9457, метрика как декларация, пакеты `logging`, `logging.pino`, `prometheus` и `otel`, фабрики плагинов `make*` |
| [0.2.0](./v0.2.0.md) | `httpEndpoint.get('/users', { … })` и пять соседей по методу, `httpEndpoint.implement`, имя команды первым аргументом `cliEndpoint`, досрочный успех pre-шага `done()`, пакеты `drizzle.pg`, `inbox` и `mcp`, трасса и метрики в ядре, `openapi.zod` → `schema.zod`, барели поимённо |
