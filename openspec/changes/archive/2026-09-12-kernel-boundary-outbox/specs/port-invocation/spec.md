# port-invocation Specification (delta)

## ADDED Requirements

### Requirement: Словарь `meta` расширяется вызывающей стороной

`Port` и `Emitter` SHALL принимать вторым тип-параметром словарь `meta`
со значением по умолчанию `MetaOf<C>`: `Port<C, M>` и `Emitter<C, M>`.
Аргументы вызова SHALL строиться тем же типом `InvokeArgs<C, M>`, поэтому
у операции без входа payload SHALL оставаться необязательным, а у
остальных — обязательным.

Тип-параметр SHALL быть точкой расширения для satellite-пакета: обёртка
вызывающей стороны объявляет собственный словарь пересечением
(`MetaOf<C> & { … }`) и SHALL оставаться присваиваемой типу ядра, потому
что параметр метода в TypeScript бивариантен. Хендлер, которому чужое
поле не нужно, SHALL продолжать объявлять зависимость типом
`Emitter<typeof Op>`.

Рантайм ядра SHALL игнорировать поля, которых не знает: конверт
собирается из полей словаря ядра, а чужие поля читает тот, кто их
объявил. Поля satellite-словарей в конверт транспорта SHALL NOT
попадать.

#### Scenario: Обёртка расширяет словарь

- **WHEN** пакет объявляет
  `type OutboxEmitter<C> = Emitter<C, MetaOf<C> & { partitionKey?: string }>`
  и отдаёт значение этого типа
- **THEN** `emit(payload, { partitionKey })` компилируется, а вызов без
  `partitionKey` — как прежде

#### Scenario: Расширенный эмиттер присваивается типу ядра

- **WHEN** хендлер объявляет зависимость типом `Emitter<typeof Op>`, а
  получает значение расширенного типа
- **THEN** это компилируется, и тело хендлера не отличается от кода с
  эмиттером ядра

#### Scenario: Чужое поле не попадает в конверт

- **WHEN** эмиттер ядра вызван со словарём, в котором есть лишнее поле
- **THEN** в конверт попадают только поля словаря ядра
