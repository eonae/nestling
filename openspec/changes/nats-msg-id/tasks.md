- [x] 3.4 Сверять окно существующего потока с настроенным и писать `warn` с

      `warn` на поток и не мешает публикации
- [x] 5.6 `double.spec`: подтверждение повтора несёт `duplicate: true`, а
      первой публикации — `false`
- [x] 5.7 `live.integration.spec`: тот же сценарий повтора против живого
      брокера под `NATS_TEST_SERVERS`. Написан; прогон против `nats:2`

      Дефект прежний и к окну дедупликации отношения не имеет
