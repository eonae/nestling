# guide-single-file

## Why

Гайд читают подряд, а собирается он двадцатью восемью страницами плюс два
файла темы. Отдать его целиком нельзя: переслать, положить рядом с
релизом или открыть с флешки — значит нести каталог, где страницы
ссылаются друг на друга по именам файлов, а оформление лежит отдельно.
Один файл снимает это ограничение: он открывается двойным кликом и не
зависит ни от соседей, ни от сервера.

Заодно чинится подсветка. Сейчас её делает `app.js` в браузере, поэтому
любая копия страницы без темы рядом показывает код серым текстом.

## What Changes

- **BREAKING** `yarn docs:build` кладёт в `docs/.site/` ровно один файл —
  `index.html`. Страниц `01-first-service.html`, `02-input.html` и
  остальных двадцати шести больше нет, как нет и постраничных адресов.
- `styles.css` и `app.js` не копируются в каталог вывода: оформление
  уходит в `<style>` внутри страницы, поведение — в `<script>`. В
  `scripts/site/` оба файла остаются источником.
- Сайдбар перечисляет все части и главы сразу; пункт ведёт якорем внутрь
  страницы, а не на соседний файл.
- Ссылка между главами `./06-config.md#секреты` становится якорем
  `#06-config--секреты`. Идентификаторы заголовков получают приставку
  главы: в одном файле `#запуск` из двух глав иначе столкнутся.
- Подсветка синтаксиса переезжает из браузера в сборку. Генератор
  размечает токены сам, и код виден подсвеченным даже при выключенном
  JavaScript.

## Non-goals

- **Текст глав.** Ни одна глава не переписывается: меняется только то,
  что генератор делает с их markdown.
- **Разметка глав.** `:::note`, `::::cards` и подписи блоков кода
  работают как работали.
- **Публикация сайта.** GitHub Pages и адреса страниц в сети — вопрос
  волны 4, здесь не решается.
- **Смена подсветчика на библиотеку.** Правила подсветки остаются теми
  же, что в `app.js`; меняется только момент, когда они применяются.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `docs-site`: результат сборки — один файл вместо страницы на главу;
  тема встроена в него, а не скопирована рядом; навигация и ссылки между
  главами ведут якорями; подсветка выполняется на сборке.

## Impact

- **Генератор:** `scripts/site/build.mjs` — состав вывода, навигация,
  ссылки, подсветка; `scripts/site/layout.html` — каркас одной страницы;
  `scripts/site/app.js` — из него уходит подсветка, остаётся тема, меню и
  ведение активного пункта; `scripts/site/styles.css` — стили разделов
  глав; `scripts/site/README.md`.
- **Документация:** `docs/README.md` — описание вывода; спека `docs-site`.
- **Проверки:** `.claude/skills/docs-audit/scripts/check.mjs` — правило
  «сгенерированный HTML не отслеживается git» продолжает работать, но
  каталог теперь содержит один файл.
- **Команды:** `yarn docs:build` и `yarn docs:dev` сохраняют имена и
  назначение.
