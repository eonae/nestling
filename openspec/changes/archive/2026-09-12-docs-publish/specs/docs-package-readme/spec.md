## MODIFIED Requirements

### Requirement: README пакета состоит из шести разделов в фиксированном порядке

README пакета SHALL быть парой файлов: `packages/*/README.md` на
английском и `packages/*/README.ru.md` на русском. Английский файл SHALL
быть тем, что показывает страница пакета в реестре.

Каждый файл пары SHALL состоять из шести частей в этом порядке: заголовок
`# @scope/name` с одной-двумя фразами «что это»; плашка статуса;
`## Установка` (`## Install`); `## Минимальный пример`
(`## Minimal example`); `## Экспорты` (`## Exports`); `## Границы пакета`
(`## Package boundaries`).

Других заголовков второго уровня SHALL NOT быть. Разделов «Быстрый старт»,
«Основные понятия», «Полный пример», «Справочник API» и «Отличия от NestJS» в
README SHALL NOT существовать: обучение живёт в `docs/guide/`, семантика — в
`docs/design/`.

Раздел минимального примера SHALL содержать ровно один блок кода.
Пошаговых объяснений и второго примера в нём SHALL NOT быть. Блок кода
SHALL быть одним и тем же в обоих файлах пары: различаются только
комментарии в нём.

#### Scenario: Лишний раздел

- **WHEN** в `packages/nestling.container/README.md` есть заголовок
  `## Quick start`
- **THEN** `yarn docs:audit` печатает ERROR с именем файла и именем заголовка

#### Scenario: Нарушенный порядок

- **WHEN** в README раздел `## Exports` стоит раньше `## Install`
- **THEN** `yarn docs:audit` печатает ERROR с фактическим порядком заголовков

#### Scenario: Полный состав

- **WHEN** оба файла пары содержат шесть разделов из требования в
  указанном порядке
- **THEN** `yarn docs:audit` по этой паре молчит

#### Scenario: README без русской пары

- **WHEN** в пакете есть `README.md`, а `README.ru.md` нет
- **THEN** `yarn docs:audit` печатает ERROR с ожидаемым путём

### Requirement: README пакета не длиннее 120 строк

Каждый файл пары README SHALL содержать не больше 120 строк. Считаются все
строки файла, включая блоки кода, таблицы и пустые строки. Потолок SHALL быть
одним для всех пакетов и обоих языков: послаблений по скоупу, размеру пакета,
числу экспортов или языку не существует.

#### Scenario: Превышение потолка

- **WHEN** `packages/nestling.app/README.md` содержит 2092 строки
- **THEN** `yarn docs:audit` печатает ERROR с фактической длиной и потолком

#### Scenario: Файл в пределах потолка

- **WHEN** оба файла пары содержат 114 строк
- **THEN** `yarn docs:audit` по длине этих файлов молчит

### Requirement: Проверки README пакетов входят в `docs:audit`

`yarn docs:audit` SHALL проверять оба файла пары README по всем требованиям
выше. Каждое нарушение SHALL быть ERROR и SHALL называть файл, а для
расхождения перечня экспортов — два списка имён: чего нет в README и чего нет
в коде.

Перечень экспортов SHALL совпадать у обоих файлов пары: имена не
переводятся.

Проверка SHALL извлекать имена из исходников пакета и SHALL NOT требовать
собранного `dist`: аудит запускается на чистом клоне до `yarn build`.

#### Scenario: Аудит на чистом клоне

- **WHEN** репозиторий склонирован, выполнен `yarn install` и не выполнен
  `yarn build`
- **THEN** `yarn docs:audit` проверяет перечни экспортов и не сообщает об
  отсутствии `dist`

#### Scenario: Перечни экспортов разошлись

- **WHEN** `README.md` называет экспорт, которого нет в `README.ru.md`
- **THEN** `yarn docs:audit` печатает ERROR с этим именем

#### Scenario: Репозиторий соответствует правилу

- **WHEN** все двадцать одна пара README приведены к структуре
- **THEN** `yarn docs:audit` печатает 0 ERROR

### Requirement: Плашка статуса ведёт на design-док и главу или рецепт

За первым абзацем каждого файла пары README SHALL идти блок цитаты —
плашка статуса.

У публичного пакета плашка SHALL называть статус разработки и содержать
хотя бы одну ссылку в папку `design/` своего языка и хотя бы одну ссылку
в `guide/` или `recipes/` своего языка. Русский файл SHALL ссылаться в
`docs/design/`, `docs/guide/` и `docs/recipes/`, английский — в
`docs/en/design/`, `docs/en/guide/` и `docs/en/recipes/`. Ссылок каждого
вида SHALL быть не больше трёх: перечень из шести design-доков перестаёт
быть ориентиром. Ссылки в `guide/` и в `recipes/` SHALL считаться одним
видом: у пакета один текст-источник, и жанр этого текста выбирает не
пакет.

У внутреннего пакета — того, чьё имя начинается с `@nestlingjs/common.`, —
плашка SHALL состоять из одной строки о том, что пакет внутренний. Ссылок
в `design/`, `guide/` и `recipes/` у него SHALL NOT быть.

#### Scenario: Плашка без ссылки на гайд

- **WHEN** README пакета `@nestlingjs/outbox` не содержит ссылки ни в
  `guide/`, ни в `recipes/` своего языка
- **THEN** `yarn docs:audit` печатает ERROR с именем файла

#### Scenario: Плашка английского README

- **WHEN** `packages/nestling.transport.cli/README.md` содержит ссылку в
  `docs/en/recipes/cli.md` и ссылку в `docs/en/design/`
- **THEN** `yarn docs:audit` по плашке этого файла молчит

#### Scenario: Плашка ведёт через границу языка

- **WHEN** `packages/nestling.transport.cli/README.md` содержит ссылку в
  `docs/recipes/cli.md`
- **THEN** `yarn docs:audit` печатает ERROR: ссылка ведёт в русский файл

#### Scenario: Слишком много ссылок

- **WHEN** плашка README перечисляет шесть design-доков
- **THEN** `yarn docs:audit` печатает ERROR с числом ссылок

#### Scenario: Внутренний пакет

- **WHEN** README пакета `@nestlingjs/common.graphs` содержит однострочную плашку без
  ссылок в документацию
- **THEN** `yarn docs:audit` по плашке этого файла молчит
