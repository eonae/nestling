## ADDED Requirements

### Requirement: Раздел установки называет peer-зависимости пакета

Раздел `## Установка` README пакета SHALL называть библиотеки, которые
приложение ставит рядом с пакетом, — то есть его `peerDependencies` вне
скоупа `@nestlingjs`. Команда установки SHALL перечислять их вместе с
самим пакетом.

Правило SHALL действовать на обе половины пары: русский README и его
английский файл называют один и тот же список.

Пакет без сторонних peer-зависимостей SHALL оставлять раздел прежним:
перечислять нечего.

#### Scenario: Пакет требует валидатор

- **WHEN** `@nestlingjs/transport.http` объявляет `zod` peer-зависимостью
- **THEN** раздел установки его README называет `zod` в команде
  установки, и то же делает английская половина

#### Scenario: Пакет без сторонних peer

- **WHEN** у `@nestlingjs/logging` нет ни одной зависимости
- **THEN** раздел установки называет один пакет

#### Scenario: Половины разошлись

- **WHEN** русский README называет `zod`, а английский — нет
- **THEN** это расхождение с требованием
