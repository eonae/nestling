## ADDED Requirements

### Requirement: Публичный экспорт несёт явную аннотацию типа

Значение, экспортируемое пакетом, SHALL нести аннотацию типа на самом
объявлении. Тип публичного имени становится написанным, а не выведенным по
случайности: если вывод где-то поедет, это видно в диффе, а не у потребителя.
Аннотация SHALL стоять на каждом экспортируемом значении: ссылка на тип
соседнего объявления не заменяет её.

#### Scenario: Экспорт DI-токена

- **WHEN** пакет экспортирует значение, тип которого возвращает вызов из
  другого модуля
- **THEN** объявление несёт аннотацию типа

#### Scenario: Алиас вместо аннотации

- **WHEN** тип экспортируемого значения объявлен отдельным `type`-алиасом
  через `typeof`
- **THEN** это расхождение с требованием: аннотация нужна на самом значении

### Requirement: Декларации собираются без проверки типов

Декларации пакета SHALL выводиться из одного файла за раз, без программы
компилятора. Проверка типов SHALL оставаться отдельной задачей и выполняться
за прогон один раз. Сборка перестаёт быть четвёртым тайпчеком того же кода.

#### Scenario: Сборка пакета

- **WHEN** пакет собран
- **THEN** сборка не проверяла типы и не читала декларации зависимостей

#### Scenario: Ошибка типов в исходнике

- **WHEN** в исходнике пакета есть ошибка типов
- **THEN** её находит задача проверки типов, а не сборка

### Requirement: Публичная поверхность не меняется от перехода

Набор публичных имён и их сигнатуры SHALL остаться прежними. Аннотация обязана
совпадать с тем, что компилятор выводил раньше; разойтись она может только
там, где новый тип тоже валиден, — поэтому совпадение проверяется диффом
собранных деклараций, а не чтением.

#### Scenario: Сверка деклараций

- **WHEN** декларации собраны до и после перехода
- **THEN** дифф пуст, кроме объявленного в предложении расхождения по `App`

### Requirement: Метод с вычисляемым именем объявлен интерфейсом

Метод класса, имя которому даёт символ, SHALL объявляться слиянием деклараций:
контракт — интерфейсом того же имени, реализация — на прототипе. Вычисляемое
имя невыразимо в декларации, выведенной из одного файла.

#### Scenario: Seam-метод приложения

- **WHEN** класс приложения объявляет метод с ключом-символом
- **THEN** декларация пакета содержит этот метод с той же сигнатурой
