## 8. Транспорт

- [x] 8.1 `McpTransport implements ITransport`: `serve(dispatch, signal)`
  строит определения и присоединяет обработчик к `HttpServer`, `close()`
  отменяет запросы и чистит сессии
- [x] 8.2 `mcp(options)` через `makeTransportDeclaration`: `info`, `server`,
  `converters`, `path`, `name`, опции сессий; способности — `value` в обе
  стороны
- [x] 8.3 Обработчик берёт `POST` и `DELETE` по своему пути и возвращает
  `false` на чужой запрос; `GET` не берёт
- [x] 8.4 Ответ: 200 с телом JSON-RPC, 202 без тела на нотификацию,
  заголовок `Mcp-Session-Id` на `initialize`
- [x] 8.5 Спеки: старт падает на нарушении объявления до открытия сокета;
  два инструмента с одним именем валят ASSEMBLE; endpoint'ы транспорта не
  попадают в документ OpenAPI
