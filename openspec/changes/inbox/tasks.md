## 1. Ядро: досрочный успех pre-юнита

- [x] 1.1 Значение `done()` и предикат `isDone` в `@nestlingjs/app`: бренд,
      которого не даёт ни `Fail`, ни добавка к контексту
- [x] 1.2 `PreResult` принимает `Done`; `ExtractAddition` исключает его, чтобы
      признак не попадал в `TAcc` и в `meta` хендлера
- [x] 1.3 `PreOptions` принимает `done?: boolean`; `PipelineImpl` ведёт признак
      рядом с `declaredFails`, `compose` объединяет дизъюнкцией, `bind` и
      деривация сохраняют; аксессор `declaresDone(pipeline)`
- [x] 1.4 Исполнение слоя: `isDone` проверяется перед `isFail` и до записи в
      контекст; следующие pre-юниты, проверка входа и хендлер пропускаются,
      ответная фаза начинается с успеха без значения, исход `.finally` —
      `completed`
- [x] 1.5 `done()` из пайплайна без признака роняет запрос ошибкой с починкой
- [x] 1.6 Проверка при создании декларации: пайплайн с признаком требует
      декларации без `output`; работает у формы с операцией и у формы со
      своим адресом, текст называет слой, декларацию и причину
- [x] 1.7 Рантайм-тесты на всё перечисленное: досрочный успех из середины
      слоя, порядок предикатов, `.ok`/`.finally` после него, ошибка без
      признака, обе формы проверки декларации
- [x] 1.8 Проверка типов фиксирует отсутствие проверки компилятором и причину
      — бюджет типов
