# Бэкенд, написанный агентами

Nestling служит агенту и человеку на равных: обоим он сокращает время между
«код написан» и «известно, верен ли он». Приложение целиком поднимается в
одном процессе. Ошибку показывает компилятор. Сборка падает раньше, чем
откроется сокет.

[Начать за пять минут](./guide/01-first-service.md)
[npm i @nestlingjs/app](https://www.npmjs.com/package/@nestlingjs/app)

```typescript
const ListUsers = httpEndpoint.get('/users', {
  output: z.array(User),
  handler: async () => [{ id: '1', name: 'Alice' }],
});

const app = makeApp({
  endpoints: [ListUsers],
  transports: [http()],
});

await app.build().run();
```

::::cards
:::card Приложение целиком в одном процессе
Фича вызывает соседа [операцией](./guide/14-features.md), а не по сети.
Поведение проверяется без брокера, контейнеров и развёртывания, а та же
декларация [разрезается на процессы](./guide/20-split.md), когда это
понадобится.
:::
:::card Ошибка при компиляции
Схема `output` типизирует хендлер, список [отказов](./guide/04-errors.md) в
декларации endpoint'а закрывает возврат незаявленной ошибки, а требования
слоя к контексту сверяются в точке `compose`.
:::
:::card Сборка падает раньше сокета
Цикл в графе, недостающая зависимость, endpoint без обязательного слоя и
ненайденный ключ конфига останавливают старт. Полный список — [таблица
проверок](./guarantees.md).
:::
:::card Проверка без сервера
Тестовая сборка `buildTest` проводит ту же декларацию по фазам до `WIRE` и
[останавливается](./guide/08-testing.md). Endpoint вызывается через тот же
пайплайн, но сокет не открывается.
:::
::::

## С чего начать

Гайд ведёт от первого сервиса к приложению из нескольких фич,
развёрнутому в нескольких процессах. Главы читаются подряд: каждая
опирается на код предыдущей.

## Когда Nestling не нужен

Сервису на один процесс, который никто не вызывает типизированным клиентом
и документацию которого никто не читает, декларации ничего не возвращают.
Там они остаются расходом, и такой сервис дешевле написать на Fastify.
Nestling окупается там, где фича переживает переезд в другой процесс, где
вызывающий хочет клиент из контракта и где документ OpenAPI обязан
следовать за кодом.
