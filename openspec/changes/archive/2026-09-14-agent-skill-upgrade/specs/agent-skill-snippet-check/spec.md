## MODIFIED Requirements

### Requirement: Каждый TypeScript-сниппет скилла лежит компилируемым файлом

Ограда блока кода в файлах скилла SHALL называть язык. Ограда без языка SHALL
быть ошибкой: снятие языка — способ обойти сверку, а не способ показать
текст. Код, который кодом не является — дерево каталогов, вывод команды, —
SHALL нести язык `text`.

Каждый блок кода на TypeScript в файлах скилла SHALL соответствовать файлу в
`packages/nestling.agent-skill/snippets/` — целиком или названным участком
этого файла. Блок SHALL быть помечен строкой `<!-- snippet: <имя файла> -->`
перед открывающей оградой; блок с участком — строкой
`<!-- snippet: <имя файла>#<имя участка> -->`.

Участок SHALL ограничиваться в файле парой комментариев
`// #region <имя участка>` и `// #endregion`. Участки SHALL NOT вкладываться
друг в друга, и имя участка SHALL быть уникально внутри файла.

Файлы `snippets/` SHALL входить в проект пакета (`tsconfig.json`) и SHALL NOT
входить в сборку (`tsconfig.build.json`). Они SHALL импортировать пакеты
`@nestlingjs/*` по их публичным именам, а не по относительным путям.

Пакеты, которые импортируют сниппеты, SHALL быть объявлены в
`devDependencies` пакета через `workspace:*`.

#### Scenario: Сниппет компилируется против настоящего API

- **WHEN** сигнатура `httpEndpoint` меняется несовместимо
- **THEN** `yarn verify` падает на таргете `typecheck` пакета
  `@nestlingjs/agent-skill` с ошибкой в файле сниппета

#### Scenario: Блок без пометки

- **WHEN** в `references/errors.md` есть блок ```typescript без строки
  `<!-- snippet: … -->`
- **THEN** `yarn verify` печатает ошибку с именем файла и номером строки

#### Scenario: Ограда без языка

- **WHEN** в `references/config.md` есть блок кода, ограда которого языка не
  называет
- **THEN** `yarn verify` печатает ошибку с именем файла и номером строки

#### Scenario: Фрагмент вместо целого файла

- **WHEN** справочник показывает четыре строки из середины сниппета
- **THEN** блок помечен участком, участок в файле ограждён комментариями, и
  файл компилируется целиком

### Requirement: Блок кода в скилле совпадает с файлом сниппета

Содержимое блока кода SHALL совпадать с содержимым названного файла
посимвольно, без учёта завершающего перевода строки. Блок с участком SHALL
совпадать с телом участка, у которого снят общий отступ; строки-комментарии
границ в блок SHALL NOT входить.

Проверка SHALL идти в обе стороны: файл `snippets/`, на который не ссылается
ни один блок кода, SHALL быть ошибкой. Файл SHALL считаться прочитанным, если
на него ссылается хотя бы один блок — целиком или участком.

Расхождение SHALL останавливать `yarn verify`: проверка SHALL выполняться одним
из таргетов, которые `verify` уже гоняет, и SHALL NOT требовать отдельной
команды.

#### Scenario: Блок отстал от файла

- **WHEN** файл `snippets/get-user.endpoint.ts` поправлен, а блок в
  `references/endpoints.md` остался прежним
- **THEN** `yarn verify` падает и печатает имя файла сниппета и имя markdown

#### Scenario: Участок отстал от файла

- **WHEN** тело участка `#reading` поправлено, а блок с пометкой
  `<!-- snippet: config.ts#reading -->` остался прежним
- **THEN** `yarn verify` падает и называет файл, участок и имя markdown

#### Scenario: Сниппет без читателя

- **WHEN** в `snippets/` лежит файл, на который не ссылается ни один блок
- **THEN** `yarn verify` падает и называет этот файл

#### Scenario: Участка нет в файле

- **WHEN** блок ссылается на участок `#reading`, а пары комментариев с этим
  именем в файле нет
- **THEN** `yarn verify` падает и называет файл и имя участка

#### Scenario: Всё сходится

- **WHEN** блоки и файлы совпадают в обе стороны
- **THEN** `yarn verify` по сниппетам молчит

### Requirement: Блоки кода переписываются из файлов одной командой

Пакет SHALL предоставлять команду, которая переписывает блоки кода в файлах
скилла содержимым файлов `snippets/`. Блок с участком SHALL переписываться
телом участка со снятым общим отступом.

Команда SHALL менять только тело блоков с пометкой `<!-- snippet: … -->` и
SHALL NOT трогать остальной текст. Запуск команды на сошедшихся файлах SHALL
не менять ни одного байта.

#### Scenario: Синхронизация после правки сниппета

- **WHEN** сниппет поправлен и выполнена команда пакета
- **THEN** блок кода в markdown содержит новую версию, а текст вокруг блока
  не изменился

#### Scenario: Синхронизация участка

- **WHEN** поправлено тело участка и выполнена команда пакета
- **THEN** блок с пометкой участка содержит новое тело, а блоки других
  участков того же файла не изменились

#### Scenario: Запуск на сошедшихся файлах

- **WHEN** команда выполняется, когда блоки и файлы уже совпадают
- **THEN** `git status` не показывает изменений
