## MODIFIED Requirements

### Requirement: Раздел «Экспорты» называет все публичные имена пакета

Раздел `## Экспорты` SHALL называть каждое публичное имя пакета: значения,
классы, типы и интерфейсы.

Множеством публичных имён SHALL считаться множество имён, экспортируемых
барелями, которые названы в поле `exports` файла `package.json` пакета.
Реэкспорты `export * from './x/index.js'` SHALL раскрываться рекурсивно.

Имена, реэкспортируемые из соседнего пакета репозитория, SHALL быть заменены
одной строкой со ссылкой на пакет-источник и в перечне SHALL NOT повторяться.

Каждый подпуть из `exports`, кроме корневого, SHALL быть отдельной группой с
заголовком по имени подпути. Пакет, у которого вместо барреля объявлен `bin`,
SHALL называть команду запуска вместо перечня имён.

#### Scenario: Имя есть в коде, но не в README

- **WHEN** барель `@nestlingjs/transport.http` экспортирует `makeHttpProbes`, а раздел
  «Экспорты» его не называет
- **THEN** `yarn docs:audit` печатает ERROR со списком имён, которых нет в README

#### Scenario: Имя есть в README, но не в коде

- **WHEN** раздел «Экспорты» называет `makeRouter`, а барель пакета такого имени
  не экспортирует
- **THEN** `yarn docs:audit` печатает ERROR со списком имён, которых нет в коде

#### Scenario: Типы считаются наравне со значениями

- **WHEN** барель экспортирует только тип `Handler` и раздел «Экспорты» его не
  называет
- **THEN** `yarn docs:audit` печатает ERROR: тип — такое же публичное имя

#### Scenario: Реэкспорт соседнего пакета

- **WHEN** `@nestlingjs/app` реэкспортирует 37 имён из `@nestlingjs/operations`, а
  его раздел «Экспорты» содержит одну строку со ссылкой на этот пакет
- **THEN** `yarn docs:audit` не требует называть эти 37 имён в README `app`

#### Scenario: Подпуть пакета

- **WHEN** `package.json` объявляет вход `./testing`, а в разделе «Экспорты» нет
  группы с этим именем
- **THEN** `yarn docs:audit` печатает ERROR с именем подпути
