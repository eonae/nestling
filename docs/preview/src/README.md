# Разметка страниц превью

Обычный Markdown плюс несколько блоков под конструкции этой темы оформления.
Сборка — `yarn docs:preview` (см. [../README.md](../README.md)).

## Заголовки и якоря

`##` — раздел статьи, `###` — подраздел. У `##` якорь обязателен: на него
ссылаются сайдбар и пейджер из `nav.mjs`.

```md
## Модульный монолит {#monolith}
### Жадный, а не ленивый
```

## Хлебные крошки и лид

Строка `{.class}` под абзацем вешает класс на этот абзац.

```md
[Nestling](index.html) / Основные концепции
{.crumbs}

# Основные концепции

Пять кирпичей, из которых собрано любое приложение.
{.lead}
```

## Блоки кода

Первое слово после забора — язык (`ts` → `typescript`), остальное попадает в
подпись над блоком. Подсветку делает `app.js` уже в браузере.

````md
```ts orders.module.ts
export const OrdersModule = { providers: [OrdersService] };
```

```ts
// без подписи — только язык
```
````

## Врезки

```md
:::note Почему «nestling»
Nestling — птенец: младший, лёгкий родственник большого Nest.
:::

:::note good Что осталось
Три знакомых типа провайдеров, `@Injectable`, инъекционные токены.
:::

:::note warn Осторожно
Ранний `listen()` в `@OnInit` невозможен by design.
:::
```

Заголовок врезки обязателен. Вариантов оформления три: без модификатора,
`good` (зелёная) и `warn` (жёлтая).

## Карточки

Сетка на первом экране. Внешний блок — четыре двоеточия, карточки — три.
После `:::card` идут иконка и заголовок, дальше текст карточки.

```md
::::cards
:::card 🧩 Модули — это значения
Не классы с декораторами, а plain-объекты.
:::
:::card ⚡ Жадный контейнер
Весь граф строится на старте.
:::
::::
```

## Таблицы

Обычные GFM-таблицы — генератор сам заворачивает их в горизонтальный скроллер.
Ячейку-отказ помечают классом `{.no}`, тогда она красится в красный.

```md
| В NestJS есть | В Nestling | Что вместо |
| --- | --- | --- |
| `forwardRef` | нет {.no} | Циклы ловятся на `build()`. |
```

Вертикальную черту внутри ячейки экранируют: `\|`.

## Списки

Обычные списки Markdown; класс `body` навешивается сам:

```md
- **Циклы** обнаруживаются при топосортировке.
- **Недостающие зависимости** видны до старта.
```

## Сырой HTML

Работает как escape-hatch для одиночной вёрстки — так сделан первый экран в
`index.md`. Внутри HTML-блока **не должно быть пустых строк**: пустая строка
закрывает блок, и остаток уедет в текст.

## Чего генератор не делает

`styles.css` и `app.js` он не трогает — оформление, тема и подсветка правятся
там напрямую. Навигация (сайдбар, пейджер, `<title>`) живёт в `nav.mjs`, а не в
тексте страниц.
