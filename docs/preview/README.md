# Превью документации

Статический HTML-превью целевой документации. **Не источник истины** — источник
намерения живёт в [`docs/design/`](../design/) и [`docs/decisions/`](../decisions/).

## Как править

Текст правится в `src/*.md`, HTML собирается генератором:

```bash
yarn docs:preview         # собрать один раз
yarn docs:preview:watch   # пересобирать при каждом сохранении в src/
```

`index.html`, `concepts.html`, `fundamentals.html`, `scaling.html` — **результат
сборки**. Руками их не редактируют: следующая сборка затрёт правку.

```
docs/preview/
├── src/
│   ├── layout.html   ← каркас страницы: шапка, разметка, подключение стилей
│   ├── nav.mjs       ← сайдбар и пейджер — единственный источник правды
│   ├── index.md · concepts.md · fundamentals.md · scaling.md   ← текст
│   └── README.md     ← справочник по разметке
├── styles.css · app.js   ← оформление и подсветка; генератор их не трогает
└── *.html                ← СГЕНЕРИРОВАНО
```

Полный справочник по разметке (заголовки, врезки, карточки, блоки кода,
таблицы) — в [`src/README.md`](./src/README.md).

## Добавить страницу

1. `src/<slug>.md` — текст;
2. запись в `PAGES` внутри `src/nav.mjs` — группа сайдбара, заголовок вкладки,
   пункты навигации, ссылки пейджера;
3. `yarn docs:preview`.

Сайдбар и пейджер собираются из `nav.mjs` для всех страниц сразу — дублировать
навигацию по страницам, как было раньше, больше не нужно.
