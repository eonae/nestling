# Превью документации

Статический HTML-просмотр гайда. **Не источник истины**: текст живёт в
[`docs/guide/`](../guide/), а источник намерения — в
[`docs/design/`](../design/) и [`docs/decisions/`](../decisions/).

## Как править

Текст правится в главах гайда, HTML собирается генератором:

```bash
yarn docs:preview         # собрать один раз
yarn docs:preview:watch   # пересобирать при каждом сохранении в docs/guide/
```

Все `*.html` в этой папке — **результат сборки**. Руками их не
редактируют: следующая сборка затрёт правку.

```
docs/preview/
├── src/
│   ├── layout.html   ← каркас страницы: шапка, разметка, подключение стилей
│   └── README.md     ← справочник по разметке глав
├── styles.css · app.js   ← оформление и подсветка; генератор их не трогает
└── *.html                ← СГЕНЕРИРОВАНО из docs/guide/
```

## Что делает генератор

- Страница на каждую главу и каждое приложение: имя файла главы плюс
  расширение `.html`. Стартовая страница `index.html` — README гайда.
- Группы сайдбара — заголовки `## Часть N. …` и `## Приложения` из
  README гайда; пункты группы — строки таблицы под заголовком. У
  открытой страницы группа раскрыта, а под ней перечислены её
  `##`-разделы.
- Пейджер внизу страницы ведёт на предыдущую и следующую страницу в
  порядке README.
- Ссылки `./NN-имя.md` переписываются в `NN-имя.html`, якоря
  сохраняются. Ссылки в другие папки `docs/` остаются относительными:
  `guide/` и `preview/` — соседи, и путь у них одинаков.
- Блок кода, который начинается со строки-комментария с путём, получает
  подпись `data-file`; сама строка остаётся в коде.

Сборка падает, если состав README и файлы `docs/guide` разошлись:
названная в README глава отсутствует, глава лежит в папке без строки в
README или ссылка `./*.md` ведёт на несуществующую главу. Текст ошибки
называет файл.

## Добавить страницу

1. Новая глава `docs/guide/<NN-имя>.md`.
2. Строка в таблице нужной части в `docs/guide/README.md`.
3. `yarn docs:preview`.

Справочник по разметке глав — [`src/README.md`](./src/README.md).
