# Снимок публичных типов до части B

Аннотации и перевод сборки на swc обязаны оставить публичную поверхность
прежней. Проверяется это не чтением, а диффом: ошибиться аннотацией можно
только там, где новый тип тоже валиден, и глазами такое не ловится.

## Где лежит

```
~/.cache/nestling/dts-snapshot/<пакет>/<путь в dist>.d.ts
```

Вне репозитория намеренно: снимок — рабочий материал одного change'а, а не
артефакт, который кто-то потом сопровождает.

| что | значение |
| --- | --- |
| коммит | `02637ac26e47eed7be01081d1b600ded986215ac` |
| файлов | 308 |
| дайджест | `307f663efabc4ff6d615edd723fd22e6b692bac4` |

Дайджест снят так — им же снимок сверяется на целостность перед сравнением:

```sh
cd ~/.cache/nestling/dts-snapshot
find . -name '*.d.ts' | sort | xargs shasum | shasum | cut -d' ' -f1
```

## Что в нём уже учтено

Коммит снимка — это часть A плюс швы `BuiltApp`. То есть расхождение по
`export interface BuiltApp`, объявленное в предложении, в снимок **уже
вошло**: сверка по задаче 6.1 обязана дать пустой дифф без исключений.

## Как сверять

```sh
yarn nx run-many -t build
diff -r ~/.cache/nestling/dts-snapshot <заново собранная копия>
```

Если снимок потерян, его восстанавливает сборка на коммите из таблицы.
