# Что вышло и что осталось

## README пакетов не менялись

Публичная поверхность прежняя: слепок 847 типов совпал со снятым до правок,
дифф пуст. README пакета описывает его API, значит правке не подлежит.
Плашка в README пакета говорит о стадии разработки, а не о сверке с кодом —
её тоже не трогали.

Изменилось то, что README пакета не описывает: конфигурация сборки, граф
задач, версия компилятора. Это записано в корневых `README.md` и
`README.ru.md` (появился `verify:strict`), в `CLAUDE.md` (таблица конфигов,
чем собирается библиотека) и в
[`ideas.md [2026-09-14]`](../../../docs/decisions/ideas.md) «Проверка
репозитория: тайпчек один за прогон, публичный тип написан».

## Примеры не мигрировали

`examples/*` изменились двумя строками каждый: из скрипта `build` ушёл
`yarn run typecheck &&`, а `tsconfig.json` перестал нести `skipLibCheck`.
Кода примеров правка не коснулась — публичный API тот же.

## Точки сверки глав — доливкой после слияния

`yarn docs:audit` даёт 0 ERROR и 66 WARN `guide-stale`: change тронул
`packages/*/src`, и плашка «сверено с кодом» у каждой главы просит
пересверки. Хэш, который туда встанет, — это merge-коммит, и заранее он
неизвестен. Точки сверки доливает Merger после слияния, отдельным коммитом.

## Снимки и сверки

| что | где |
| --- | --- |
| снимок деклараций | `~/.cache/nestling/dts-snapshot`, см. [snapshot.md](./snapshot.md) |
| таблица мест | [places.md](./places.md) |
| замеры прогона | раздел «Порядок задаёт граф» в [design.md](./design.md) |

Сверка публичной поверхности шла двумя способами. Текстовый дифф `.d.ts`
ловит изменение записи — им поймано расхождение имени параметра в
декларации `OnStart`. Слепок типов через checker ловит изменение смысла и
не реагирует на запись — он и есть доказательство, что поверхность не
поехала: аннотация через импортированное имя даёт `TokenFamily<T>` вместо
синтезированного `import("…").TokenFamily<T>`, и текст расходится там, где
тип тот же.
