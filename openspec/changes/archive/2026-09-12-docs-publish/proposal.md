## Why

Документация собирается локально и никуда не публикуется: `yarn docs:build`
печатает сайт в `docs/.site/`, а этот каталог не отслеживается git. Пакеты
уже лежат в реестре, и у фреймворка есть пользователи вне репозитория —
им сайта не видно вовсе.

Второе: вся документация русская. Читатель, нашедший `@nestlingjs/app` в
реестре, открывает README пакета и не может его прочесть. Корневой
`README.md` английский и честно предупреждает «Documentation and examples
are in Russian» — предупреждение вместо документации.

Это волна 5 уборки документации из
[ideas.md [2026-09-05] «Структура документации»](../../../docs/decisions/ideas.md):
«GitHub Actions и Pages, домен, новые инварианты `docs:audit`». Запись
оставила волне два открытых вопроса — язык сайта и домен; оба закрываются
здесь. Строка [61 `docs-publish`](../../../docs/decisions/roadmap.md)
roadmap.

## What Changes

- **Сайт публикуется на GitHub Pages** по адресу
  `https://eonae.github.io/nestling`. Выкладывает workflow `docs.yml` по
  тегу `v*` — тем же событием, что публикует пакеты в реестр. Сайт
  описывает опубликованную версию, а не текущее состояние `main`.
- **Документация выходит на двух языках целиком.** Английский —
  основной: адрес раздела `/guide/01-first-service/`, `lang="en"`,
  `x-default` в hreflang. Русский лежит в подпути `/ru/`.
- **BREAKING. Английский текст живёт в `docs/en/` зеркалом**: путь внутри
  зеркала повторяет путь оригинала от корня репозитория. Русские файлы
  `docs/` остаются на месте, ссылки на них не переезжают.
- **BREAKING. README пакета становится парой**: `packages/*/README.md`
  английский, `packages/*/README.ru.md` русский. Английский попадает в
  тарбол и виден на странице пакета в реестре. 21 README переводится, все
  проверки `docs:audit` идут по обеим сторонам пары.
- **Генератор печатает два дерева из одной модели.** Источник резолвится
  по языку, поиск и `nestling-docs.html` печатаются на каждый язык,
  шапка получает переключатель, страница — `alternate` на пару.
- **Планы уходят с сайта.** `roadmap.md` и `deferred.md` перестают быть
  источниками: это рабочие списки того, кто пишет фреймворк, они меняются
  каждым change'ом, и перевод устаревал бы быстрее, чем выходил. Ссылки
  на них переписываются в адрес GitHub — правилом, которое уже есть.
- **Паритет языков проверяется**: `docs:audit` падает, если у
  публикуемого файла нет пары, если оглавления пар разошлись по составу
  или если ссылка внутри `docs/en/` ведёт в русский файл. Отставание
  перевода по плашке «сверено с кодом» — предупреждение, а не ошибка.
- **У английского текста свои правила стиля.** Скилл `docs-style`
  получает английскую часть и список запрещённых слов для неё, а словарь
  соответствий терминов лежит в `docs/en/glossary.md`: 15 000 строк
  перевода должны называть `Fail` и «фича» одинаково во всех файлах.
- **CI проверяет документацию**: `ci.yml` прогоняет `yarn docs:audit` и
  `yarn docs:build`. Расхождение оглавления ловится в ветке, а не на
  теге, когда публикация уже идёт.

## Capabilities

### New Capabilities

- `docs-publication`: сайт выкладывается на GitHub Pages по тегу релиза;
  базовый адрес, `sitemap.xml`, `robots.txt`, `canonical`, `.nojekyll`;
  проверка сборки документации в CI.
- `docs-bilingual`: документация существует на двух языках; раскладка
  файлов, паритет пар, словарь терминов, правила английского текста и
  инварианты `docs:audit`, которые всё это держат.

### Modified Capabilities

- `docs-site`: генератор собирает два языка вместо одного — источник
  резолвится по языку, адреса русских разделов получают префикс `/ru/`,
  на каждый язык печатаются своё дерево, свой `nestling-docs.html` и свой
  индекс поиска; шапка несёт переключатель языка; из списка источников
  удаляются `roadmap.md` и `deferred.md`.
- `docs-package-readme`: README пакета — пара из английского `README.md`
  и русского `README.ru.md`; требования к структуре, потолку строк,
  плашке и разделу «Экспорты» действуют на обе стороны.
- `docs-guide-layout`: папки жанра `docs/guide/` и `docs/recipes/`
  существуют в двух экземплярах — русском на месте и английском в
  `docs/en/`; оглавление полно в обе стороны внутри своего языка.

## Impact

- **Документация**: `docs/en/**` — новое зеркало (~15 000 строк
  перевода: 21 глава гайда, 8 рецептов, 13 design-доков, 5 страниц корня,
  21 README пакета). `docs/README.md` — правила ведения двуязычной
  документации.
- **Генератор**: `scripts/site/build.mjs`, `scripts/site/sections.mjs`,
  `layout.html`, `home.html`, `app.js`, `styles.css`,
  `scripts/site/README.md`.
- **Пакеты**: `packages/*/README.md` → английский, `README.ru.md` —
  русский. Манифесты не меняются: `files: ["dist"]` уносит в тарбол
  только `dist`, а README реестр берёт отдельно.
- **CI**: новый `.github/workflows/docs.yml`; шаги проверки документации
  в `.github/workflows/ci.yml`.
- **Проверки**: `.claude/skills/docs-audit/scripts/check.mjs` —
  инварианты паритета; `.claude/skills/docs-style/` — английская часть
  скилла и её линтер.
- **Вне репозитория**: в настройках GitHub Pages источником выбирается
  GitHub Actions. Это действие пользователя, а не шаг change'а.

## Non-goals

- **Домен `nestling.dev`.** Адрес остаётся `eonae.github.io/nestling`.
  Переезд на свой домен — одна строка `CNAME` и запись DNS, когда домен
  появится.
- **Версионирование документации.** Сайт показывает одно состояние —
  последний тег. Архив версий не печатается.
- **Перевод `decisions/`, `history/`, `openspec/` и `CLAUDE.md`.** Это
  документы того, кто работает внутри репозитория; они не публикуются и
  остаются русскими.
- **Перевод кода и примеров.** Комментарии, JSDoc и `examples/` остаются
  русскими; строки, которые процесс отдаёт наружу, уже английские по
  `runtime-message-language`.
- **Машинный перевод на лету.** Английский текст лежит в репозитории
  файлами и проходит те же проверки, что русский.
