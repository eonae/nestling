# config-sections Specification (delta)

## ADDED Requirements

### Requirement: Префикс секции задаётся на экземпляр

Префикс секции SHALL допускать вычисление на экземпляр: пакет, у которого
экземпляров несколько, SHALL объявлять секцию на каждое имя. Секция одного
имени SHALL создаваться один раз: повторное объявление с тем же именем
SHALL отдавать тот же токен.

Имя экземпляра SHALL превращаться в префикс тем же правилом, что имя поля
в ключ: `SCREAMING_SNAKE_CASE`. Имя `'default'` SHALL давать префикс
пакета без добавки.

Дескриптор `.keys` SHALL быть у каждого экземпляра свой: право привязки
адресует ключи одного экземпляра, а не всего пакета.

#### Scenario: Два экземпляра читают разные ключи

- **WHEN** пакет объявляет секцию с префиксом `http` для экземпляров
  `'default'` и `'admin'`
- **THEN** первый читает `HTTP_PORT`, второй — `HTTP_ADMIN_PORT`

#### Scenario: Повторное объявление даёт тот же токен

- **WHEN** секция для имени `'admin'` объявлена дважды
- **THEN** обе ссылки указывают на один узел графа

#### Scenario: Привязка адресует один экземпляр

- **WHEN** источник привязан к `.keys` экземпляра `'admin'`
- **THEN** он отвечает за `HTTP_ADMIN_PORT` и `HTTP_ADMIN_HOST`, но не за
  `HTTP_PORT`
