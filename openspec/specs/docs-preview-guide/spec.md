# docs-preview-guide Specification

## Purpose

`yarn docs:preview` собирает страницы `docs/preview/*.html` из глав гайда
`docs/guide/*.md` и его README. Отдельных markdown-источников для превью
не существует: текст страницы берётся только из соответствующей главы.
Порядок страниц и группы боковой навигации повторяют структуру README —
заголовки `## Часть N. …` и таблицы под ними. Ссылки между главами и
подписи блоков кода переносятся в HTML без правки текста глав.
Несовпадение README и содержимого `docs/guide` — ошибка сборки.

## Requirements

### Requirement: Превью собирается из глав гайда

Скрипт `yarn docs:preview` SHALL собирать `docs/preview/*.html` из
`docs/guide/README.md` и глав `docs/guide/*.md`. Стартовая страница
`index.html` SHALL быть README гайда; каждая глава и каждое приложение
SHALL получать свою страницу с именем файла главы и расширением `.html`.
Отдельных markdown-источников в `docs/preview/src` SHALL NOT существовать:
каркас `layout.html`, стили и скрипт подсветки остаются, текст берётся
только из гайда.

Порядок страниц SHALL совпадать с порядком таблиц README гайда. Глава,
названная в README, но отсутствующая в `docs/guide`, и глава, лежащая в
`docs/guide`, но не названная в README, SHALL быть ошибкой сборки с именем
файла.

#### Scenario: Сборка из гайда

- **WHEN** выполнено `yarn docs:preview`
- **THEN** в `docs/preview` лежат `index.html` и по одной странице на
  каждую строку таблиц README гайда; страниц, которых нет в README, нет и
  в `docs/preview`

#### Scenario: Глава без строки в README

- **WHEN** в `docs/guide` добавлен файл `26-extra.md`, а в README он не
  упомянут
- **THEN** сборка падает, называя файл

#### Scenario: Пересборка при изменении главы

- **WHEN** запущено `yarn docs:preview --watch` и изменён файл главы
- **THEN** страница главы пересобрана, остальные не тронуты руками

### Requirement: Навигация строится из частей гайда

Группы сайдбара SHALL соответствовать заголовкам `## Часть N. …` и
`## Приложения` README гайда; пункты группы — строкам таблицы под
заголовком, с заголовком главы из первой ячейки. У открытой страницы
группа SHALL быть раскрыта, а подпункты SHALL строиться из `##`-заголовков
главы. Пейджер внизу страницы SHALL вести на предыдущую и следующую
страницу в порядке README.

#### Scenario: Сайдбар открытой главы

- **WHEN** открыта страница главы 3
- **THEN** группа «Часть 1» раскрыта, глава 3 отмечена активной, под ней
  перечислены `##`-разделы главы, остальные группы свёрнуты

#### Scenario: Пейджер

- **WHEN** открыта страница главы 6
- **THEN** пейджер ведёт назад на главу 5 и вперёд на главу 7; на
  последнем приложении ссылка «вперёд» отсутствует

### Requirement: Ссылки и блоки кода переносятся без правки глав

Ссылки вида `./NN-имя.md` и `./appendix-*.md` SHALL переписываться в
`NN-имя.html`; якоря SHALL сохраняться. Ссылки в другие папки `docs/`
(`../design/…`, `../decisions/…`, `../glossary.md`) SHALL оставаться как
есть: `guide/` и `preview/` — соседние папки, относительный путь совпадает.
Ссылка `./NN-имя.md` на несуществующую главу SHALL быть ошибкой сборки.

Блок кода, первая строка которого — комментарий `// путь`, SHALL получать
подпись `data-file` из этого пути; строка из кода SHALL NOT удаляться.
Путь переносится дословно и не разбирается: сборка не проверяет, что он
существует, и не знает, из какого каталога взят файл.
Текст глав SHALL NOT требовать разметки, отличной от обычного markdown:
`:::note` и `::::cards` остаются доступными, но не обязательны.

#### Scenario: Ссылка на соседнюю главу

- **WHEN** глава содержит `[глава 6](./06-config.md#секреты)`
- **THEN** страница содержит ссылку `06-config.html#секреты`

#### Scenario: Ссылка на дизайн

- **WHEN** глава содержит `[design/errors.md](../design/errors.md)`
- **THEN** ссылка остаётся `../design/errors.md`

#### Scenario: Подпись блока кода

- **WHEN** блок кода начинается со строки `// examples/users-service/src/app.ts`
- **THEN** блок получает `data-file="examples/users-service/src/app.ts"`,
  а строка-комментарий остаётся в коде

#### Scenario: Битая ссылка на главу

- **WHEN** глава ссылается на `./99-missing.md`
- **THEN** сборка падает, называя главу и ссылку

### Requirement: Разделы README вне «Часть N.»/«Приложения» не становятся страницами

`docs/guide/README.md` MAY содержать заголовки `##`, отличные от «Часть
N. …» и «Приложения» — например, «Карта понятий». Такой заголовок SHALL
NOT открывать новую группу навигации сайдбара и SHALL NOT прерывать
сборку `yarn docs:preview`.

Строка таблицы, первая ячейка которой не является ссылкой `[текст](./имя.md)`
на главу, SHALL NOT становиться отдельной страницей превью — даже если
ссылка на главу встречается в другой ячейке той же строки. Такая строка
SHALL NOT считаться расхождением README и `docs/guide` при проверке
полноты состава.

#### Scenario: Раздел без ссылок на главу в первой ячейке

- **WHEN** между существующими разделами README добавлен заголовок `##
  Карта понятий` с таблицей, где первая ячейка каждой строки — понятие
  (текст или код), а не ссылка на главу
- **THEN** `yarn docs:preview` собирается без ошибок, а строки этой
  таблицы не порождают новых страниц в `docs/preview`

#### Scenario: Ссылка на главу в непервой ячейке строки

- **WHEN** строка такой таблицы содержит ссылку на главу `./NN-имя.md` не
  в первой ячейке
- **THEN** эта ссылка не превращает строку в страницу превью и не требует,
  чтобы заголовок раздела совпадал с «Часть N.» или «Приложения»
