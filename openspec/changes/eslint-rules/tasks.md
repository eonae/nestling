## 1. Правило `conditional-spread`

- [ ] 1.1 `src/conditional-spread.ts`: обход `SpreadElement`, чей родитель —
  `ObjectExpression`; спред в литерале массива пропускается. Аргумент
  разбирается двумя формами: тернарник ровно с одной пустой ветвью и
  логическое `&&`
- [ ] 1.2 Классификация выражения на булевость по форме: сравнение
  (`===`, `!==`, `==`, `!=`, `<`, `<=`, `>`, `>=`), `in`, `instanceof`,
  `!x`, `Boolean(x)`, литералы `true`/`false`, `&&` и `||` с булевыми
  обеими сторонами; `??` небулев, тип выражения не читается
- [ ] 1.3 Автофикс тернарника применяется, когда булев **итоговый** тест —
  тот, что встанет слева от `&&`: для `test ? obj : {}` это `test`, для
  `test ? {} : obj` — его отрицание
- [ ] 1.4 Отрицание в автофиксе: `===`↔`!==` и `==`↔`!=` инвертируются
  оператором; реляционные и остальные булевы формы оборачиваются `!(…)`;
  внешнее `!` снимается. Текст берётся из `sourceCode`, скобки
  расставляются по приоритету
- [ ] 1.5 Вторая половина: `...(x && obj)` с небулевым по форме `x` —
  сообщение о ловушке нуля и пустой строки плюс suggestion
  `x !== undefined && obj`; автофикса у этой половины нет
- [ ] 1.6 `meta`: `type: 'suggestion'`, `fixable: 'code'`,
  `hasSuggestions: true`, `schema: []` — опций у правила нет. Сообщения
  по-английски (capability `runtime-message-language`), JSDoc модуля
  по-русски
- [ ] 1.7 `src/conditional-spread.spec.ts` на `RuleTester` с парсером
  typescript-eslint: валидные кейсы (спред в массиве, обе ветви пустые,
  булев `&&`), невалидные с проверкой `output` для автофикса и
  `suggestions` для ловушки, кейс без фикса для небулевого итога

## 2. Правило `no-process-globals`

- [ ] 2.1 `src/no-process-globals.ts`: ошибка на обращении к `env` и
  `argv` у идентификатора `process` — по имени свойства и вычисляемым
  строковым литералом; запись через `globalThis.process` разбирается той
  же веткой
- [ ] 2.2 Идентификатор `process`, объявленный локально, пропускается:
  привязка ищется через `sourceCode.getScope`, как в `dependency-list`.
  Обращение через промежуточную переменную не ловится — и это записано в
  JSDoc модуля
- [ ] 2.3 Именованный импорт `env` или `argv` из `node:process` и
  `process` — ошибка на спецификаторе
- [ ] 2.4 Разрешённая форма: `process.argv` непосредственным аргументом
  вызова маркера. Имя маркера — идентификатор `argv` либо локальное имя
  импорта, чьё исходное имя `argv`; срез аргументом маркера остаётся
  ошибкой
- [ ] 2.5 Сообщения называют шов: окружение — источник `env()` в привязке
  конфига, командная строка — маркер `argv()` в аргументе сборки. Текст
  по-английски, `meta.schema: []`
- [ ] 2.6 `src/no-process-globals.spec.ts` на `RuleTester`: валидные
  (`argv(process.argv)`, переименованный импорт маркера, локальный
  `process`), невалидные (`process.env.X`, `process.argv.slice(2)`,
  `globalThis.process.env`, импорт из `node:process`, срез аргументом
  маркера)
