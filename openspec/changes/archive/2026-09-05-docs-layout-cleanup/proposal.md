# docs-layout-cleanup

## Why

Разбор всей документации
([discussions/11](../../../docs/history/discussions/11-docs-structure-and-site.md))
нашёл два беспорядка. Первый — дублирование по жанрам: один факт описан в
нескольких местах, и места расходятся. Второй — гайд смешивает
последовательный рассказ и самостоятельные рецепты в одном нумерованном
списке. Уборка разбита на пять волн; этот change — первая, и он трогает
только инфраструктуру, не переписывая ни одного абзаца документации.

Три дубля закрываются здесь.

1. **Сгенерированный HTML лежит в git.** `docs/preview/*.html` занимает
   10 673 строки. Каждая правка главы даёт диффы в двух местах, а папка
   `preview/` нарушает правило «папка определяет статус документа»:
   статуса у результата сборки нет.
2. **Правила ведения документации написаны трижды.** Карта `docs/` и
   список правил повторяются в `CLAUDE.md`, `docs/README.md` и
   `docs/design/README.md`.
3. **Таблицы пакетов, примеров и глав написаны трижды.** Корневые
   `README.md` и `README.ru.md` дублируют друг друга и `docs/README.md`.
   Плюс приложение В гайда (152 строки) повторяет карту понятий из
   `docs/guide/README.md`, добавляя к ней пути файлов примеров, которые
   устаревают при каждом переименовании.

Записи в `docs/decisions/ideas.md` по этому решению пока нет: обсуждение
зафиксировано дискуссией d/11, запись журнала добавляется этим change.

## What Changes

- Генератор переезжает из `docs/preview/` в `scripts/site/` вместе с
  темой: `layout.html`, `styles.css`, `app.js` и оба README папки.
  Каталог `docs/preview/` удаляется целиком.
- Вывод сборки идёт в `docs/.site/`, каталог попадает в `.gitignore`.
  Из git удаляются 30 файлов `docs/preview/*.html`.
- Команды переименовываются: `docs:preview` становится `docs:build`,
  `docs:preview:watch` становится `docs:dev`. Слово «preview» уходит из
  репозитория.
- Правила ведения документации остаются в одном экземпляре — в
  `docs/README.md`. Раздел «Обязанность держать доки в синхроне» в
  `CLAUDE.md` и «Три правила» в `docs/design/README.md` заменяются
  ссылкой на него.
- Корневые `README.md` и `README.ru.md` сокращаются: таблицы пакетов,
  примеров и частей гайда заменяются ссылками на `docs/README.md` и
  оглавление гайда.
- Приложение В (`docs/guide/appendix-c-coverage.md`) удаляется вместе со
  строкой в оглавлении гайда.
- `docs:audit` получает проверку: сгенерированный HTML не отслеживается
  git.

## Non-goals

- **Переезд «Что проверяется до первого запроса» и приложения Б.** В
  плане они стояли в этой волне. Отложены в волну 3 по технической
  причине: сборка рендерит только `docs/guide/`, и документ, вынесенный
  из этой папки, перестаёт быть страницей сайта до волны 4. Волна 1 не
  должна оставлять недостижимых страниц.
- **Разделы сайта, URL-пути, поиск, стартовая страница, метаданные,
  подсветка на сборке.** Волна 4.
- **Публикация: GitHub Actions, Pages, домен.** Волна 5.
- **README пакетов и их потолок строк.** Волна 2.
- **Разделение гайда на путь и рецепты, деление главы 12.** Волна 3.
- **Правка `docs/design/`, `docs/decisions/` и `docs/history/`.** Кроме
  ссылки вместо правил в `design/README.md` и новой записи журнала.

## Capabilities

### New Capabilities

- `docs-site`: сборка HTML-сайта документации. Расположение генератора и
  темы, каталог вывода вне git, имена команд, состав страниц из глав
  гайда, навигация из оглавления, перенос ссылок и подписей блоков кода.
  Заменяет `docs-preview-guide` целиком.

### Modified Capabilities

- `docs-preview-guide`: удаляется. Все четыре требования переносятся в
  `docs-site` с новыми путями и именами команд. Поведение генератора в
  этой волне не меняется — меняются только адреса и названия, поэтому
  сценарии переносятся один в один.

## Impact

- **Код:** не затронут. Пакеты, тесты и `yarn verify` не меняются.
- **Скрипты:** `scripts/preview/build.mjs` переезжает в
  `scripts/site/build.mjs`; константы путей и тексты ошибок называют
  новые каталоги.
- **Конфигурация:** `package.json` — имена скриптов; `.gitignore` —
  `docs/.site/`.
- **Документация:** `docs/README.md`, `CLAUDE.md`, `docs/design/README.md`,
  `README.md`, `README.ru.md`, `docs/guide/README.md`. Удаляются
  `docs/preview/` и `docs/guide/appendix-c-coverage.md`.
- **Проверки:** `.claude/skills/docs-audit/scripts/check.mjs` — новая
  проверка отслеживаемого HTML. Существующие проверки остаются зелёными:
  приложение В уходит вместе со своей строкой в оглавлении, поэтому
  инвариант «карты полны в обе стороны» не нарушается.
- **Ссылки:** файлы, ссылавшиеся на `docs/preview/`, правятся в том же
  change. Ссылки из глав гайда на `../design/…` не трогаются: вывод в
  `docs/.site/` сохраняет соседство с `docs/design/`, на котором эти
  ссылки держатся.
