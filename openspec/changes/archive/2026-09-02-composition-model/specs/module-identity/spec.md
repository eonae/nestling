# module-identity Specification (delta)

## MODIFIED Requirements

### Requirement: Модуль описывает только группировку провайдеров

Интерфейс `Module` в `@nestling/container` SHALL состоять из `name`,
`providers` и `dependsOn`. Поля `endpoints` у модуля SHALL NOT существовать
ни на одном уровне: декларации объявляются на фиче и на плагине.

Поле `imports` SHALL быть переименовано в `dependsOn`. Смысл поля —
принадлежность («без этого модуль не работает»), а не доступ: провайдеры
видны всем, кто может импортировать токен.

#### Scenario: Модуль с endpoint'ами не компилируется

- **WHEN** объявлен `makeModule({ name: 'm', endpoints: [SomeEndpoint] })`
- **THEN** компилятор отвергает объявление: у модуля нет такого поля

#### Scenario: Транзитивная регистрация по dependsOn

- **WHEN** модуль `A` объявляет `dependsOn: [B]` и зарегистрирован в билдере
- **THEN** провайдеры `B` зарегистрированы, а их узлы несут метку `'B'`

#### Scenario: Discovery не читает поле с модуля

- **WHEN** приложение собрано из фич и плагинов
- **THEN** endpoint'ы обнаружены проходом по фичам и плагинам, а модули в
  обнаружении не участвуют
