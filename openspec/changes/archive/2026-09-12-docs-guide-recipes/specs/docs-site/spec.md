## MODIFIED Requirements

### Requirement: Сайт собирается из перечисленных источников

Скрипт `yarn docs:build` SHALL собирать один файл `docs/.site/index.html`
из источников, перечисленных в `scripts/site/sections.mjs`. Других файлов
`.html` в каталоге вывода SHALL NOT быть. Генератор и тема SHALL лежать в
`scripts/site/`: `build.mjs`, `sections.mjs`, `layout.html`, `styles.css`,
`app.js`.

Источник SHALL быть одного из двух видов: папка с оглавлением
`README.md` и отдельная страница. Порядок источников в `sections.mjs`
SHALL задавать порядок разделов собранного файла. Список SHALL включать
папки `docs/guide/` и `docs/recipes/` и страницы `docs/guarantees.md` и
`docs/from-nestjs.md`.

README папки-источника SHALL открывать её разделы, а каждый её файл
SHALL становиться разделом с якорем по имени файла. Отдельных
markdown-источников для сайта SHALL NOT существовать: текст раздела
берётся только из соответствующего файла.

Файл, названный в README папки, но в ней отсутствующий, и файл, лежащий в
папке, но не названный в её README, SHALL быть ошибкой сборки с именем
файла. Проверка SHALL выполняться для каждой папки-источника отдельно.

Команда `yarn docs:dev` SHALL пересобирать файл при изменении любого
источника из `sections.mjs` и файлов `scripts/site/`. Имён
`docs:preview` и `docs:preview:watch` SHALL NOT существовать.

#### Scenario: Сборка из двух папок и двух страниц

- **WHEN** выполнено `yarn docs:build`
- **THEN** в `docs/.site` лежит `index.html` и ни одного другого файла
  `.html`, а в нём — раздел на каждую главу `docs/guide/`, на каждый
  рецепт `docs/recipes/` и на каждую страницу из `sections.mjs`

#### Scenario: Рецепт без строки в README

- **WHEN** в `docs/recipes/` добавлен файл `metrics.md`, а в
  `docs/recipes/README.md` он не упомянут
- **THEN** сборка падает, называя файл

#### Scenario: Пересборка при изменении рецепта

- **WHEN** запущено `yarn docs:dev` и изменён файл рецепта
- **THEN** файл собран заново и содержит новый текст рецепта

#### Scenario: Старых имён команд нет

- **WHEN** выполнено `yarn docs:preview`
- **THEN** yarn сообщает, что такого скрипта нет

### Requirement: Навигация строится из частей источников

Группы сайдбара SHALL строиться по источнику. У папки с заголовками
`## Часть N. …` каждый такой заголовок SHALL давать свою группу, а её
пункты — строки таблицы под заголовком с заголовком файла из первой
ячейки. У папки без таких заголовков вся папка SHALL давать одну группу с
заголовком из `sections.mjs`. Страница-источник SHALL давать один пункт
в группе, названной в `sections.mjs`.

Пункт SHALL вести якорем на раздел внутри файла. Все группы и все пункты
SHALL быть перечислены в сайдбаре сразу. У файла, который читатель видит,
SHALL раскрываться список его `##`-разделов, а его пункт SHALL быть
отмечен активным; читаемый файл определяется по положению прокрутки.
Пейджер в конце раздела SHALL вести якорями на предыдущий и следующий
раздел в порядке `sections.mjs`.

#### Scenario: Сайдбар открытого файла

- **WHEN** файл открыт в браузере
- **THEN** сайдбар перечисляет две части пути, группу рецептов и группу
  страниц корня, и каждый пункт ведёт якорем внутрь файла

#### Scenario: Читаемый раздел

- **WHEN** читатель прокрутил файл до главы 3
- **THEN** пункт главы 3 отмечен активным, под ним перечислены её
  `##`-разделы, у остальных пунктов подпунктов нет

#### Scenario: Пейджер через границу источника

- **WHEN** читатель дошёл до конца последней главы пути
- **THEN** пейджер ведёт вперёд на первый рецепт в порядке
  `sections.mjs`; в конце последнего раздела ссылки «вперёд» нет

### Requirement: Ссылки и блоки кода переносятся без правки текста

Ссылка на файл источника SHALL переписываться в якорь по имени файла:
`./NN-имя.md` и `../recipes/имя.md` — в `#NN-имя` и `#имя`. Якорь внутри
файла SHALL переноситься с приставкой: `./NN-имя.md#якорь` →
`#NN-имя--якорь`. Ссылка `./README.md` SHALL вести на начало раздела
своего источника. Ссылка на файл источника, которого нет, SHALL быть
ошибкой сборки.

Ссылка в файл вне источников (`../design/…`, `../decisions/…`,
`../glossary.md`) SHALL разрешаться относительно каталога исходного файла
и записываться относительно `docs/.site/`. У файла из `docs/guide/`
результат совпадает с исходной записью; у файла из корня `docs/` путь
получает ведущий `../`.

Идентификатор заголовка внутри файла SHALL получать приставку из имени
файла и двух дефисов: одинаковые заголовки разных файлов иначе
столкнулись бы в одном документе.

Блок кода, первая строка которого — комментарий `// путь`, SHALL получать
подпись `data-file` из этого пути; строка из кода SHALL NOT удаляться.
Путь переносится дословно и не разбирается: сборка не проверяет, что он
существует, и не знает, из какого каталога взят файл.

<!-- docs-style: off -->
Подсветка синтаксиса SHALL выполняться при сборке: разметка токенов
SHALL лежать в самом HTML.
<!-- docs-style: on --> Показ подсвеченного кода SHALL NOT зависеть от
выполнения JavaScript в браузере.

Текст SHALL NOT требовать разметки, отличной от обычного markdown:
`:::note` и `::::cards` остаются доступными, но не обязательны.

#### Scenario: Ссылка из главы в рецепт

- **WHEN** глава содержит `[рецепт](../recipes/cli.md#repl)`

- **WHEN** `docs/from-nestjs.md` содержит

- **THEN** файл содержит ссылку `../design/errors.md`

- **THEN** идентификаторы у них разные: `09-logging--проверка` и

- **WHEN** глава ссылается на `./99-missing.md`
- **THEN** сборка падает, называя файл и ссылку

### Requirement: Разделы README вне «Часть N.» не попадают в сайт

README папки-источника MAY содержать заголовки `##`, отличные от «Часть
N. …» — например, «Карта понятий» или «Как читать». Такой заголовок
SHALL NOT открывать новую группу навигации сайдбара и SHALL NOT прерывать
сборку `yarn docs:build`.

Строка таблицы, первая ячейка которой не является ссылкой
`[текст](./имя.md)` на файл папки, SHALL NOT становиться разделом сайта —
даже если ссылка на файл встречается в другой ячейке той же строки. Такая
строка SHALL NOT считаться расхождением README и папки при проверке
полноты состава.

#### Scenario: Раздел без ссылок на файл в первой ячейке

- **WHEN** между существующими разделами README добавлен заголовок `##
  Карта понятий` с таблицей, где первая ячейка каждой строки — понятие
  (текст или код), а не ссылка на файл папки
- **THEN** `yarn docs:build` собирается без ошибок, а строки этой таблицы
  не порождают новых разделов в `index.html`

#### Scenario: Ссылка на файл в непервой ячейке строки

- **WHEN** строка такой таблицы содержит ссылку на файл папки не в первой
  ячейке
- **THEN** эта ссылка не превращает строку в раздел сайта и не требует,
  чтобы заголовок раздела совпадал с «Часть N.»
