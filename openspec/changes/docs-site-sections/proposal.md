# docs-site-sections

## Why

Сайт публикует четыре источника из десяти. `scripts/site/sections.mjs`
перечисляет `docs/guide/`, `docs/recipes/`, `docs/guarantees.md` и
`docs/from-nestjs.md` — 33 файла и 8304 строки. За его пределами остались
`design/`, README пакетов, глоссарий, соглашения, roadmap и deferred:
ещё 39 файлов и 7789 строк, которые запись
[ideas.md [2026-09-05] «Структура документации»](../../../docs/decisions/ideas.md)
называет публикуемыми. Читатель фреймворка видит половину документации,
написанной для него.

У раздела нет собственного адреса. Вывод — один файл `index.html`, адрес
главы — якорь в нём. Поисковик индексирует один документ вместо
семидесяти двух. Ссылка в мессенджере показывает одно и то же название
для любой главы: `<title>` в документе один, `description`, Open Graph и
`canonical` не проставляются вовсе. Поиска по документации нет.

Это волна 4 из пяти волн уборки документации — «Сайт: разделы, URL-пути,
ссылки на GitHub, подсветка на сборке, поиск, стартовая страница,
метаданные». Волны 1–3 закрыты change'ами `docs-layout-cleanup` (#40),
`docs-package-readmes` (#58) и `docs-guide-recipes` (#59); структура папок
устоялась, и генератор правится один раз. Состав волны — в той же записи
журнала и в [d/11 §5](../../../docs/history/discussions/11-docs-structure-and-site.md).

Пакеты вышли в npm (`npm-publish`, #63), и у фреймворка появились
читатели вне репозитория. Для них документация и существует.

## What Changes

- **BREAKING** `yarn docs:build` кладёт в `docs/.site/` дерево страниц:
  `guide/01-first-service/index.html`, `recipes/cli/index.html`,
  `design/container/index.html` и так далее. Адрес раздела — путь
  `/guide/01-first-service/`, а не якорь `#01-first-service`. Ссылка на
  раздел в прежней форме перестаёт работать.
- Рядом с деревом собирается `nestling-docs.html` — вся документация
  одним самодостаточным файлом, как её собирает сборка сегодня. Ссылки
  внутри него остаются якорями, тема и подсветка встроены. Файл
  пересылают, кладут рядом с релизом и открывают двойным кликом.
- Источников становится десять. Добавляются `docs/design/` с бейджем
  «целевое V1», README публикуемых пакетов как раздел `/reference/`,
  `docs/glossary.md`, `docs/conventions.md`, `docs/decisions/roadmap.md`
  и `docs/decisions/deferred.md`.
- Появляется третий вид источника — пакеты. Его оглавление лежит в
  разделе «Пакеты» файла `docs/README.md`: четыре группы уже названы там,
  и второй копии списка не заводится.
- Ссылка в неопубликованный файл (`decisions/ideas.md`, `archlog.md`,
  `history/`, `openspec/`) переписывается в абсолютный адрес на GitHub.
  Сейчас плашки design-доков ведут в `ideas.md`, и на сайте такая ссылка
  дала бы 404.
- Стартовая страница `/` собирается из нового `docs/index.md` по
  отдельному шаблону. Сегодня первым разделом идёт README гайда.
- Поиск: индекс собирается на сборке в JSON, страница ищет по нему в
  браузере. Сервер для поиска не нужен.
- Метаданные на каждой странице: `title` с названием раздела,
  `description`, `canonical`, Open Graph, favicon. Плюс `sitemap.xml`,
  `robots.txt` и `404.html` в корне вывода.
- Базовый адрес сайта — параметр сборки. Домен выбирается в волне 5;
  без параметра ссылки собираются относительными, и дерево открывается с
  любого пути.
- `yarn docs:dev` поднимает локальный сервер на `@nestlingjs/common.static-server`
  и пересобирает дерево при изменении источника. Дерево путей по `file://`
  не открывается, поэтому сервер обязателен.
- Подсветка получает правила для `bash` и `json`: сейчас 52 и 3 блока
  показаны серым текстом, потому что генератор знает только TypeScript.
- `yarn docs:audit` проверяет новые инварианты: у каждого раздела есть
  строка в оглавлении своего источника, `docs/index.md` существует, вывод
  сборки не отслеживается git.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `docs-site`: результат сборки — дерево страниц по URL-путям плюс один
  файл рядом; источников десять, вид источника третий — пакеты; адрес
  раздела — путь; ссылка в неопубликованное ведёт на GitHub; стартовая
  страница собирается отдельным шаблоном; страница несёт метаданные и
  поиск; `docs:dev` поднимает сервер.

## Non-goals

- **Публикация.** GitHub Actions, Pages, домен и `canonical` с этим
  доменом — волна 5, строка roadmap #61 `docs-publish`. Здесь сборка
  только готовит файлы и принимает базовый адрес параметром.
- **VitePress или Starlight вместо своего генератора.** Отвергнуто в
  записи [2026-09-05] и в [d/11 §7](../../../docs/history/discussions/11-docs-structure-and-site.md):
  пришлось бы переписать врезки и карточки и потерять инварианты сборки.
- **shiki как зависимость.** План волны называл её для подсветки на
  сборке, но подсветку на сборке уже сделал `guide-single-file` (#43).
  Остаток пункта — два языка правилами генератора, а не пакет весом в
  мегабайты.
- **Текст глав, рецептов и design-доков.** Ни один из 72 файлов не
  переписывается: меняется то, что генератор делает с их markdown.
  Исключение — новый `docs/index.md` и правки оглавлений там, где их
  требует новый источник.
- **Английская версия сайта.** Открытый вопрос 1 записи [2026-09-05]:
  сайт русский целиком, английская страница проекта — отдельно и позже.
- **Версионирование документации и переводы.** Повод вернуться к вопросу
  о готовом генераторе, а не задача этого change'а.
- **Диаграммы mermaid.** Один блок на всю документацию; остаётся текстом.

## Impact

- **Генератор:** `scripts/site/build.mjs` — состав вывода, адреса,
  источники, метаданные, индекс поиска; `scripts/site/sections.mjs` —
  десять источников и третий вид; `scripts/site/layout.html` — каркас
  страницы раздела; новый шаблон стартовой страницы;
  `scripts/site/app.js` — поиск и навигация между страницами;
  `scripts/site/styles.css` — оформление поиска, бейджа раздела и
  стартовой страницы; `scripts/site/README.md` — описание всего этого.
- **Документация:** новый `docs/index.md`; `docs/README.md` — карта и
  правила ведения, раздел «Пакеты» становится оглавлением источника;
  `docs/decisions/ideas.md` — отметка о волне 4 в записи [2026-09-05];
  `docs/decisions/roadmap.md` и `archlog.md` — статус change'а.
- **Проверки:** `.claude/skills/docs-audit/scripts/check.mjs` — новые
  инварианты; `.gitignore` — состав вывода.
- **Скрипты:** `package.json` — `docs:dev` с сервером, параметр базового
  адреса у `docs:build`.
- **Зависимости:** новых внешних нет. Локальный сервер берётся из
  `@nestlingjs/common.static-server`.
