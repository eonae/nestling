## MODIFIED Requirements

### Requirement: Сниппеты приложения собираются в тесте

Спека пакета SHALL собирать приложение из сниппетов вызовом `buildTest` для
значения `app` из `snippets/app.ts`. Сборка SHALL доходить до фазы WIRE, то есть
проходить BOOTSTRAP, BUILD, INIT и WIRE.

Провайдеры сниппетов SHALL NOT подменяться: смысл проверки в том, что собирается
тот же граф, который получит читатель, скопировав сниппеты. Допустимы две
подмены: конфигурация (`config`), потому что без неё сборка останавливается на
обязательном поле, и корневой логгер, потому что иначе тест печатает в консоль.

Всё, что останавливает BUILD, SHALL останавливать `yarn verify`: политика
корня, endpoint без объявленного слоя, ребро между фичами, незарегистрированный
провайдер шага слоя, форма io, которую транспорт не несёт.

#### Scenario: Endpoint не проходит политику корня

- **WHEN** `snippets/app.ts` объявляет `everyEndpoint(…).hasLayer(traced)`,
  а один из сниппетов-endpoint'ов идёт без `pipeline:`
- **THEN** `yarn verify` падает с сообщением BUILD, которое называет этот
  endpoint

#### Scenario: Шаг слоя не объявлен провайдером

- **WHEN** сниппет пайплайна добавляет класс-шаг и не вносит его в `providers:`
  плагина
- **THEN** `yarn verify` падает на сборке приложения из сниппетов

#### Scenario: Сниппеты согласованы

- **WHEN** сниппеты собираются в приложение и конфигурация связана
- **THEN** тест проходит, и в выводе нет записей логгера приложения
