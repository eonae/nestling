# module-isolation-testing

## Purpose

`testModule(M, { stubs })` поднимает мини-приложение вокруг одного модуля
(с его `imports`), kernel-модулем конфига и перечисленными стабами — тот же
`TestApp`, что у тестового корня, с теми же `call`/`get`/`close`. Для модуля
в изоляции `stubs` — это **поставка недостающего**, а не подмена боевого
узла: неудовлетворённые импорты обязаны быть застабаны явно, и ошибка
перечисляет все недостающие токены разом. Форма пар «токен → значение»
выбрана так, чтобы контрактные стабы (`stub(Contract, impl)`) легли в неё
аддитивно, когда появятся контракты.

## Requirements

### Requirement: `testModule` поднимает один модуль в изоляции

`@nestling/testing` SHALL экспортировать
`testModule(module, options?): Promise<TestApp>`, собирающую мини-приложение
вокруг одного модуля (с его `imports`), kernel-модулем конфига и
перечисленными стабами. Результат SHALL быть тем же `TestApp`, что у
`assembleTest`: те же фазы 0–3, те же `call`/`get`/`close`.

Поле `stubs` SHALL принимать пары «токен → значение» — для модуля в изоляции
это поставка недостающего, а не подмена. Форма SHALL оставаться совместимой
с будущим `stub(Contract, impl)`.

#### Scenario: Модуль без соседей

- **WHEN** `await testModule(UsersModule, { stubs: [[ILogger, noopLogger]] })`
- **THEN** приложение собрано из одного модуля, его ручки вызываются через
  `app.call`

#### Scenario: Токены видны без экспорта

- **WHEN** тест лежит внутри пакета модуля и называет его внутренний токен
- **THEN** стаб ставится без добавления токена в публичный экспорт пакета

### Requirement: Неудовлетворённые импорты обязаны быть застабаны явно

Если у модуля в изоляции остаются зависимости без провайдера, `testModule`
SHALL завершаться ошибкой, перечисляющей **все** недостающие токены — с
указанием потребителя каждого.

#### Scenario: Ошибка называет всё недостающее

- **WHEN** модуль требует `ILogger`, `IClock` и `UsersRepository`, а
  застабан только `ILogger`
- **THEN** ошибка перечисляет `IClock` и `UsersRepository` в одном
  сообщении, а не падает на первом
