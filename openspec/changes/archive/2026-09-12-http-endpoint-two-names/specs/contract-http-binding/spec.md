## MODIFIED Requirements

### Requirement: `http:` не меняет вид операции и её вызывающие стороны

Наличие секции `http` SHALL NOT влиять ни на вид операции, ни на её
вызывающие стороны (`.caller`/`.emitter`), ни на биндинг реализации через
`implement`: операция с `http:` остаётся тем же направление-нейтральным
значением, адресуемым по шине под своим именем.

#### Scenario: Вызов по шине работает как прежде

- **WHEN** операция с `http:` реализована через `implement` и вызвана
  инжектированным `.caller`
- **THEN** вызов идёт по шине, а секция `http` в этом пути не участвует

#### Scenario: Одно значение — два пути доставки

- **WHEN** операция с `http:` реализована `httpEndpoint.implement`
- **THEN** внешний клиент зовёт её по HTTP, а внутренний потребитель — по
  шине, и оба читают один и тот же интерфейс операции
