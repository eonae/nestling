## ADDED Requirements

### Requirement: Каждый TypeScript-сниппет скилла лежит компилируемым файлом

Каждый блок кода на TypeScript в файлах скилла SHALL соответствовать файлу в
`packages/nestling.agent-skill/snippets/`. Блок SHALL быть помечен строкой
`<!-- snippet: <имя файла> -->` непосредственно перед открывающей оградой.

Файлы `snippets/` SHALL входить в проект пакета (`tsconfig.json`) и SHALL NOT
входить в сборку (`tsconfig.build.json`). Они SHALL импортировать пакеты
`@nestlingjs/*` по их публичным именам, а не по относительным путям.

Пакеты, которые импортируют сниппеты, SHALL быть объявлены в
`devDependencies` пакета через `workspace:*`.

#### Scenario: Сниппет компилируется против настоящего API

- **WHEN** сигнатура `httpEndpoint` меняется несовместимо
- **THEN** `yarn verify` падает на таргете `typecheck` пакета
  `@nestlingjs/agent-skill` с ошибкой в файле сниппета

#### Scenario: Блок без пометки

- **WHEN** в `references/errors.md` есть блок ```typescript без строки
  `<!-- snippet: … -->`
- **THEN** `yarn verify` печатает ошибку с именем файла и номером строки

### Requirement: Блок кода в скилле совпадает с файлом сниппета

Содержимое блока кода SHALL совпадать с содержимым названного файла посимвольно,
без учёта завершающего перевода строки.

Проверка SHALL идти в обе стороны: файл `snippets/`, на который не ссылается ни
один блок кода, SHALL быть ошибкой.

Расхождение SHALL останавливать `yarn verify`: проверка SHALL выполняться одним
из таргетов, которые `verify` уже гоняет, и SHALL NOT требовать отдельной
команды.

#### Scenario: Блок отстал от файла

- **WHEN** файл `snippets/get-user.endpoint.ts` поправлен, а блок в
  `references/endpoints.md` остался прежним
- **THEN** `yarn verify` падает и печатает имя файла сниппета и имя markdown

#### Scenario: Сниппет без читателя

- **WHEN** в `snippets/` лежит файл, на который не ссылается ни один блок
- **THEN** `yarn verify` падает и называет этот файл

#### Scenario: Всё сходится

- **WHEN** блоки и файлы совпадают в обе стороны
- **THEN** `yarn verify` по сниппетам молчит

### Requirement: Блоки кода переписываются из файлов одной командой

Пакет SHALL предоставлять команду, которая переписывает блоки кода в файлах
скилла содержимым файлов `snippets/`.

Команда SHALL менять только тело блоков с пометкой `<!-- snippet: … -->` и
SHALL NOT трогать остальной текст. Запуск команды на сошедшихся файлах SHALL
не менять ни одного байта.

#### Scenario: Синхронизация после правки сниппета

- **WHEN** сниппет поправлен и выполнена команда пакета
- **THEN** блок кода в markdown содержит новую версию, а текст вокруг блока
  не изменился

#### Scenario: Запуск на сошедшихся файлах

- **WHEN** команда выполняется, когда блоки и файлы уже совпадают
- **THEN** `git status` не показывает изменений

### Requirement: nx пересчитывает проверки при правке скилла

Именованные входы `nx.json` SHALL включать `{projectRoot}/snippets/**/*` и
`{projectRoot}/skill/**/*`, чтобы правка скилла или сниппета делала
закэшированные результаты `typecheck` и `test` недействительными.

#### Scenario: Правка markdown скилла

- **WHEN** изменён `skill/SKILL.md` и выполняется `yarn verify`
- **THEN** таргет `test` пакета выполняется заново, а не берётся из кэша
